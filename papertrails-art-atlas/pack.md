# Papertrails 종이오리기 아트 아틀라스 3종

Papertrails의 종이 오리기 스타일 2D 아트 아틀라스 모음입니다. 동물 스프라이트 시트, 게임 아이콘 시트, 월드 아트 아틀라스와 각각의 json 메타데이터가 들어 있습니다.
